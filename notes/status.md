## v0 / v1 / v1.5 — shipped

- **v0 manifest CLI:** `python3 scripts/gain_manifest.py` produces three
  manifest files in `metadata/` (12 rows × CSV / JSON / Markdown).
- **v1 verifier:** `python3 scripts/gain_verify.py` walks every source URL,
  records status into `metadata/verification.json`. First live run: 8/12 OK,
  4 failed (3 ENCODE search URLs return 404; SCREEN returned 429). Drift
  surfaced and recorded — exactly the v1 contract.
- **v1.5 switch-hierarchy explorer:** `python3 scripts/gain_switch_explorer.py`
  reads `metadata/switch_hierarchy.csv` (9 nodes × 30 edges, hand-curated),
  validates every link against `sources.json`, joins in modality/stage/
  tissue, and emits `notes/switch_hierarchy.md` (per-node evidence report).
- **Dependencies added:** zero. Stdlib only across all three CLIs.
- **Lines of code:** ~110 (manifest) + ~145 (verifier) + ~165 (explorer).
  Supporting prose is larger than the code in aggregate, but no individual
  "future architecture" document exceeds the working code it describes.
